# SPEC-aozora-export: 青空文庫形式書き出し

作成日: 2026-07-30（2026-08-08 改訂: サイト別方言対応を追加）
ステータス: **確定**（Issue #133 起票時の調査メモ＋2026-07-30 確認で策定。Issue #137 でサイト別方言をスコープへ追加）
親SPEC: SPEC-vertical-editor / 起点Issue: #133, #137

## 1. 目的

小説投稿サイト（カクヨム・小説家になろう等）への転載用に、
縦書きエディタで執筆したVFM原稿を青空文庫形式のプレーンテキストへ変換して取り出せるようにする。

役割分担は変えない: 原稿の実体はGitHub・組版はVivliostyleのまま。
本機能は「エディタで開いている本文の読み取り専用の変換・書き出し」であり、原稿には一切手を加えない。

## 2. スコープ（確定）

| 論点 | 決定 |
|---|---|
| 対象範囲 | **開いている章のみ**（投稿サイトは1話ずつ貼り付ける運用のため。複数章結合は必要になったら別Issue） |
| 出力の受け取り方 | **クリップボードへコピー＋.txtダウンロードの両対応**。ダイアログに変換結果プレビューを表示 |
| 変換先の記法 | **書き出し先サイトを選択して出し分ける**（青空文庫／カクヨム／小説家になろう。Issue #137 で追加）。青空文庫選択時は純粋な青空文庫注記のみ |
| 変換対象の本文 | エディタの**編集中の内容**（未保存の編集も含む。保存状態と無関係に今見ているものが出る） |

### スコープ外

- 逆方向（青空文庫形式 → VFM）のインポート
- 複数章の結合書き出し・全章一括書き出し
- DBスキーマ変更・サーバー処理（変換はクライアント内で完結する純関数）

## 3. 変換仕様

エディタの入力補助ツールバーが挿入する記法（ルビ・傍点・縦中横・割注・改ページ・コメント）が
変換対象のすべて（Issue #133 調査メモ）。順序は下表の上から適用する。

| # | VFM（ネコノテ記法） | 青空文庫形式 |
|---|---|---|
| 1 | フロントマター（先頭の `---` ブロック） | 除去 |
| 2 | HTMLコメント `<!-- -->`（作者メモ） | 除去（行全体がコメントの行は行ごと除去） |
| 3 | 画像記法 `![…](…){.illust-*}` | 除去（行全体が画像の行は行ごと除去。テキスト出力に画像は載らない） |
| 4 | `<div class="page-break"></div>`（改ページ） | `［＃改ページ］` |
| 5 | `<span class="warichu"><span>前</span><span>後</span></span>`（割注） | `［＃割り注］前［＃改行］後［＃割り注終わり］`（後半なしは `［＃割り注］前［＃割り注終わり］`） |
| 6 | `<span class="tenten">…</span>`（傍点） | `…［＃「…」に傍点］` |
| 7 | `<span class="tcy">…</span>`（縦中横） | `…［＃「…」は縦中横］` |
| 8 | `{親文字|よみ}`（ルビ） | `｜親文字《よみ》`（常に `｜` 付き——親文字の境界が曖昧にならない安全形） |
| 9 | 見出し `# …` | 記号を外してプレーン行にする（見出し注記は付けない。話タイトルはサイト側で入力する運用のため） |

- 段落構造（空行区切り）・改行はそのまま保つ（変換で行構造を変えない）
- ツールバー操作で作れる記法のネスト（例: 傍点の中に縦中横）は内側から順にすべて変換する
- 傍点・縦中横の注記が参照する対象文字列は**表示文字**にする（中身にルビがある場合は親文字のみ。
  例: `<span class="tenten">{漢字|かんじ}</span>` → `｜漢字《かんじ》［＃「漢字」に傍点］`）
- 上記以外のHTMLタグ・Markdown強調等は変換しない（そのまま出る。ツールバー外の手書き記法は関知しない）

### 3.1 サイト別ポストプロセス（Issue #137）

書き出し先にカクヨム／なろうを選択した場合、§3 の青空文庫形式へ変換した後段で
以下のポストプロセスを適用する（出典は Issue #137 の一次情報調査:
カクヨム・なろう両ヘルプセンター。両サイトともルビ以外の青空文庫注記は解釈されない）。

| 青空文庫形式 | カクヨム | なろう |
|---|---|---|
| `｜親文字《よみ》`（ルビ） | そのまま | そのまま |
| `…［＃「…」に傍点］` | `《《…》》`（カクヨム記法） | 中黒ルビ `｜対象《・・》` で代用（対象が10文字超は1文字ずつ `｜対《・》｜象《・》` に分割） |
| `…［＃「…」は縦中横］` | 注記を除去（対象の本文は残す） | 同左 |
| `［＃改ページ］` | 行ごと除去（話分割はサイト側の単位） | 同左 |
| `［＃割り注］…［＃割り注終わり］` | マーカーを除去し中身を本文化 | 同左 |

- 傍点の注記は直前の表示文字列を参照する。注記直前のテキストが対象と一致しない場合
  （傍点対象にルビが含まれる等——カクヨムは傍点とルビの併用不可・なろうはルビの入れ子不可）は、
  注記だけを落として本文とルビを残す
- ルビの文字数上限（カクヨム: 親文字20字・ルビ50字／なろう: 親文字10字・ルビ10字）を超える
  ルビを変換後テキストから検出し、ダイアログに警告を列挙する（変換結果自体は変えない）

### 既知の制限（受容）

- 本文自体に `《` `》` `｜` `［＃` が含まれる場合の青空文庫エスケープ（`※［＃…］` 注記）・
  カクヨムの `｜《` エスケープは行わない
- 青空文庫選択時、投稿サイトが解釈するのは青空文庫注記の一部のみ。解釈されない注記は
  素のテキストとして表示されるため、ダイアログに注意書きを出す

## 4. UI

- エディタツールバー右側（ビルドボタンの並び）に「書き出し」ボタンを追加。章未選択時は無効
- 押すと書き出しダイアログを開く:
  - 書き出し先サイトの選択（青空文庫／カクヨム／小説家になろう。既定は青空文庫。
    切り替えるとプレビュー・注意書きが追随する）
  - 変換結果のプレビュー（読み取り専用・スクロール）
  - ルビ文字数上限の超過警告（該当がある場合のみ。§3.1）
  - 「クリップボードにコピー」「.txt をダウンロード」ボタン
  - 注意書き（選択サイトごとの変換内容・未保存の編集も含まれる旨）
- ダウンロードのファイル名は章ファイル名の拡張子を `.txt` に置き換えたもの（例: `chapter01.md` → `chapter01.txt`）

## 6. 受け入れ基準

1. ルビ・傍点・縦中横・割注・改ページを含む章を書き出すと、§3 の対応表どおりの青空文庫注記になる
2. コメント・フロントマター・画像記法が出力に一切現れない（行ごと消え、余計な空行が増えない）
3. コピーで変換結果がクリップボードに入り、ダウンロードで `.txt` ファイルが保存される
4. 未保存の編集がある状態でも、いまエディタに見えている内容が変換される（原稿・保存状態には影響しない）
5. カクヨムを選ぶと傍点が `《《…》》` になり、縦中横・改ページ・割注の注記が §3.1 の表どおり除去される
6. なろうを選ぶと傍点が中黒ルビになり、ルビ以外の注記が除去される
7. ルビ文字数上限（§3.1）を超えるルビがあると、ダイアログに該当箇所が警告として列挙される
