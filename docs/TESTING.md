# ネコノテAI 回帰テストチェックリスト

全機能の回帰テストを一周するためのチェックリスト。リファクタリング段階の完了後・セキュリティ修正後・リリース前に実施する。

- 構成は利用フロー順（manual.md と対応）。各項目は「操作 → 期待結果」の1行チェック形式
- ここに載っているのは**回帰確認の主要経路**。機能ごとの網羅的な検証手順は各 `SPEC-*.md` の E2E 節を参照（本書内で「深掘り→SPEC-xxx」と表記）
- NG項目は GitHub Issue に起票し（1 Issue = 1件）、末尾の記録表に Issue 番号を残す。修正は別セッション（`/fix-issue`）で行う

## 0. 前提と注意（実施前に必ず読む）

### 環境

- ローカル dev サーバー（`npm run dev`）またはブラウザペインで実施。Google ログインが必要（ペインは独立Cookie領域のため、ペイン内でのログインが必要）
- DB・GitHub 連携は本番と共通。**実データを壊さない**ことを最優先する

### データ保護ルール

- [ ] 検証は**検証専用プロジェクト**（例: 「回帰テスト用」）を新規作成して実施し、終了時に削除して原状復帰する
- [ ] 実プロジェクト・実ノート・実原稿リポジトリには**一切触れない**（閲覧もレビュー実行もしない）
- [ ] GitHub 連携系（原稿・エディタ）の検証は検証用リポジトリ `<poc-repo>` を使う。PAT の対象に `<poc-repo>` が含まれていることを事前確認
- [ ] 検証で作成したノート・イラスト・スレッド・スケジュールも終了時に削除する

### 回帰テストではやらないこと（環境・実運用を壊すため。深掘り検証時のみ個別に計画して実施）

- PAT の削除・再登録（登録済み表示の確認まで。削除すると実PATの値はユーザーの再入力が必要になる）
- API キーを外すエラー表示テスト（環境変数操作を伴う）
- Zenn の公開投稿（`published: true`。実際に公開されてしまう。下書き `false` までとする）
- cron リマインドメールの実送信
- 本番 DB への直接 UPDATE を伴う検証

## 7. 原稿と校正・講評（深掘り→SPEC-proofreading / SPEC-proofread-selection / SPEC-manuscript-history / SPEC-vertical-editor-phase4）

検証プロジェクトの repo を `<poc-repo>` に設定して実施。

- [ ] base_path 配下の `.md`/`.txt` がファイル一覧に出て、開くと読み込み専用で本文表示。当日の進捗が自動記録される
- [ ] 「履歴」でコミット一覧→選択で行単位色分け diff 表示

## 8. 縦書きエディタ（深掘り→SPEC-vertical-editor-phase2〜5 / SPEC-aozora-export / SPEC-repo-setup）

`<poc-repo>` で実施。

### 表示・編集・保存

- [ ] 章一覧が entry 順に表示される（entry 未登録は末尾に印つき）
- [ ] 章を開く→本文が入力ペインに出て、数秒後に縦書きプレビュー（ページ分割・ノンブル）が出る。編集がデバウンス後に反映される
- [ ] `Cmd/Ctrl+S`→コミットメッセージ確認→コミットが GitHub に存在する
- [ ] 未保存のままリロード→復元バナー→復元で編集が戻る
- [ ] 別経路で同ファイルを更新してから保存→競合メッセージ→マージビューで取り込み→再保存が成功する

### ツールバー・コメント

- [ ] ルビ: 選択→ボタン→読み入力→ `{選択|読み}` に置換され、プレビューで組まれる。傍点・縦中横も同様
- [ ] `Cmd/Ctrl+/` で選択範囲がコメント化される。コメント一覧に出現順で並び、クリックでジャンプ。プレビューに一切現れない
- [ ] 画像 D&D→種別選択→ `images/` へコミット＋挿入記法追記→プレビューに表示される
- [ ] 字数カウントが本文のみ（コメント・記法・ルビ読み除外）。プレビュー完了後は実ページ数表示

### 全体・設定・ビルド

- [ ] 全体プレビュー: 全章が entry 順に結合され、通しのページ分割・ノンブルが出る
- [ ] 新規章作成: 雛形入りでコミットされ、entry に自動追記される
- [ ] 書籍設定フォーム: 書誌情報/章順/組み設定/奥付の変更→差分プレビュー→コミット→反映を確認
- [ ] 入稿ビルド: タグ提案→実行→ Actions 起動を確認（PDF 完成までの待機は任意。リンク到達までで可）
- [ ] 青空文庫書き出し: ルビ・傍点入りの章で変換→注記形式の出力。コピー/ダウンロードが動く。カクヨム/なろう切替で注記が変わる

### ブランチ（Phase 5）

- [ ] ブランチ作成→即切替（URL に `?branch=`）→編集・保存が新ブランチに入り、デフォルトブランチは不変
- [ ] PR 作成→ GitHub に PR ができる。マージ＆ブランチ削除後に開き直すとデフォルトへフォールバック＋トースト

### 相互リンク

- [ ] エディタ「レビュー」→原稿タブが同じ章で開く。原稿タブ「エディタで開く」→エディタが同じ章で開く
