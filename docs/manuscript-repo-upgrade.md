# 既存の原稿リポジトリの更新ガイド

原稿リポジトリは、作成した時点のテンプレート（`docs/templates/manuscript-repo/`）の写しである。
テンプレートはその後も直されているが、**すでに作った原稿リポジトリには自動では反映されない**。
このガイドは「いつ作ったリポジトリに、何を取り込む必要があるか」を日付順に引くための索引である。

- 作成: 2026-11-11（ドキュメント突き合わせで新設。それまで手順は manual とテンプレート README の計9か所に分かれていた）
- 対象読者: 2026-11-03 より前に原稿リポジトリを作った人
- **手順の本文はここに写していない**。各行の「手順の所在」から、manual またはテンプレート README の該当節を開く
  （同じ手順を2か所に書くと、片方だけ直されて食い違うため）

## 使い方

1. 自分の原稿リポジトリを作った日を確かめる（最初のコミットの日付。初期セットアップなら「原稿リポジトリを初期作成」のコミット）
2. 下の一覧で、**その日より後の日付の行**がすべて対象になる
3. 「取り込まないとどうなるか」を読み、必要なものだけ取り込む。**全部を取り込む必要はない**
   （使っていない機能の行は飛ばしてよい）

## まとめて済ませる近道

一覧のうち **★ の付いた5行は、どれも `themes/nekonote-parts.css` の中の変更**である。
このファイルを自分で編集していなければ、次の2手で5行ぶんがまとめて済む。

1. `themes/nekonote-parts.css` を、本リポジトリの `docs/templates/manuscript-repo/themes/nekonote-parts.css` で置き換える
2. 判型テーマ（縦書きは `theme-bunko-a6.css` と `theme-b6.css`）の `:root` に、ノンブル・柱の4つのスロット変数を追記する
   （→ テンプレート README「ノンブル・柱 › 既存リポジトリへの反映」）

**必ず2つをセットで行う。** `nekonote-parts.css` だけを置き換えると、スロット変数が未定義のままになり、
ノンブルも柱も出なくなる（エラーは出ない）。置き換えたあとは、エディタの全体プレビューでノンブル・柱・挿絵の位置を確かめる。

`nekonote-parts.css` を自分で編集している場合は丸ごと置き換えず、各行の手順に従って該当箇所だけを直す。

## 優先して取り込むもの

ビルドが失敗する・動かないものは3つだけである。まずこの3つを確かめる。

- **`package-lock.json`**（2026-10-14 より前に作ったリポジトリ。入稿ビルド・EPUBビルドが失敗する）
- **EPUB 設定の継承形と `mkdir -p output`**（2026-11-01 より前。EPUB の章構成がずれる・ビルドが失敗する）
- **電子配布用PDF のワークフロー**（2026-11-01 より前。電子配布用PDF を使う場合のみ）

ほかは見た目に関わるもので、該当する機能（アプリからの挿絵の挿入・ノンブル位置の変更・横書きなど）を使うときに取り込めば足りる。

## このガイドの保守

テンプレート（`docs/templates/manuscript-repo/`）を変えたときは、既存の原稿リポジトリへの影響を確かめ、
影響があればこの一覧に1行足す。手順の本文は従来どおり manual かテンプレート README に書き、ここからは所在だけを指す。
